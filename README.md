## Quran Tab Landing Page

A responsive landing page for **Quran Tab**, a browser extension that displays a random Quranic verse whenever a new tab is opened.

# Features

- Responsive design for desktop and mobile
- Sticky navigation with smooth scrolling
- Feature sections and browser download options
- Interactive FAQ accordion using HTML and CSS
- Hover effects and transitions

# Technologies

- HTML5
- CSS3
- Sass (SCSS)
- Flexbox
- CSS Variables
- Media Queries
- CSS Selectors and Pseudo-elements
